intervention because the proposed revision would not have improved the
line; a Verifier-aware behaviour); the same Wilson 95\% formula at

Figure~\ref{fig:case-improvement} tracks the same three cases across
training. For zero-shot and trained single-agent baselines no Verifier
loop is run at test time, so by construction every line is either
Case~1 (correct draft) or Case~4 (wrong draft) and Case~6a is zero. The
\textbf{Train acc.} columns report the peak single-step training-time

half-widths there exceed $\pm.18$, so we report point values only and
treat these columns as diagnostic rather than for hypothesis testing.

\textsuperscript{$\dagger$}\,Common training-case identifiers (all trained

these cases was encountered at least once by every trained run):
\textsc{Train-A} = \texttt{single-w2-retirement-sick-pay-social-security-tip}
(easy: common single-filer 1040 with retirement, sick-pay, and SS-tip
income; near saturation for the larger backbone);
\textsc{Train-B} = \texttt{single-multiple-w2-excess-social-security-tax-same-ein}
(mid-difficulty: requires detecting and refunding excess Social-Security
withholding across multiple W-2s);
\textsc{Train-C} = \texttt{single-w2-box12-code-a-b-alaska}
(mid-difficulty: single-filer with W-2 Box-12 codes (A/B) and
Alaska-specific state-credit handling; DPA-GRPO improves over the
strongest single-agent baseline (DAPO) by a consistent
${\sim}5$\,pp at both backbones).
Per-case scores are the maximum single-step accuracy observed during
training. Held-out test split is identical across all rows
(\texttt{test\_fraction}=0.2, \texttt{split\_seed}=42).
\textsuperscript{$\ddagger$}\,For each backbone we report the best
configuration: 4B uses 10 cases/step, 8B uses 3 cases/step. The full
sweep over training-cases-per-step is reported in
Table~\ref{tab:ours-ablation}.
\textsuperscript{$\S$}\,\emph{Paired McNemar comparison (same $152$ test
lines).} Let $b$ = lines correct under \emph{Ours} but incorrect under
the strongest same-backbone baseline, and $c$ = the reverse. We use
McNemar's exact test (continuity-corrected $\chi^2_{1}$) since the same
test items are scored by both methods. \textsc{4B}: \emph{Ours} vs
\emph{Generator-only GRPO 4B}, $b{=}\langle b_{4}\rangle$,
$c{=}\langle c_{4}\rangle$, $p{=}\langle p_{4}\rangle$.
\textsc{8B}: \emph{Ours} vs \emph{Generator-only DAPO 8B},
$b{=}\langle b_{8}\rangle$, $c{=}\langle c_{8}\rangle$,
$p{=}\langle p_{8}\rangle$. Per-line correctness vectors and the
script that produced these numbers are released with the code
(\texttt{eval/mcnemar.py}); App.~\ref{app:cis} also reports a
$10{,}000$-resample paired-bootstrap 95\% CI on the
\emph{Ours~$-$~baseline} difference at each backbone, which is the
appropriate measure of paired uncertainty.
